# File Organizer

## Description
The File Organizer is a simple Linux shell script that sorts file names into categories based on their file extensions.

It identifies Documents, Images, Audio, and Other files.

## Requirements
- Linux operating system
- Bash shell

## Files Included
- organize_files.sh - Main solution script
- sample_files.txt - Sample input file

## How to Use

1. Open a Linux terminal.
2. Navigate to the project folder.
3. Make the script executable:

   chmod +x organize_files.sh

4. Run the script:

   ./organize_files.sh

5. View the results displayed in the terminal.

## Sample Input
The sample input includes documents, pictures, audio files, spreadsheets, and videos.

## Expected Output
The script displays each file name and its assigned category.
